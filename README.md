# 荒岛上的纽约 · 潮生

一座受地形、道路、建筑容量和水电供应约束的虚构海岛都会。默认世界有七百多栋建筑、住宅街区、商务核心、中央公园、港口、两座桥梁与高架地铁；外缘保留森林与山地。

- 在线：https://corzfree.cn/chaosheng-world/
- GitHub Pages：https://corzfree.github.io/chaosheng-world/
- 原野群岛：https://corzfree.cn/chaosheng-world/isles/

## 游玩

拖动平移，右键或 Alt 拖动旋转，滚轮/双指缩放。点击楼宇查看用途、楼层和实际居民。街道视角提供低位镜头，W / S 或屏幕按钮沿已连接道路漫游。

选择住宅、商务、混合、工业、公园分区后点击地块改区；有人居住的建筑受住房容量保护。“修路”接通已有规划路段。推进 90 天会按道路与水电服务完成施工、安排入住。可以暂停地铁或封闭东桥，观察交通及服务变化。关闭服务不会拆除桥梁或轨道。

“开拓荒岛”可以从没有楼宇的岛屿起步，也可以生成另一座成熟都会。都市与原野群岛独立保存，支持 JSON 导入/导出和 PNG 画面导出。

## 模拟规则

本项目是城市模拟，不是纽约真实地图或实测数据。以下是明确的模型标定：

- 每世界单位代表 2 米，每层楼约 3.6 米。
- 建成楼层与占地面积决定住房和岗位；在建部分不提前提供容量。
- 住宅按可用楼面面积 / 35 计算容量；商业按营业面积 / 25 计算岗位。
- 每个住宅地块产生 floor(居民 / 2) 名求职者，只分配到道路可达、有剩余容量的岗位。
- 通勤 OD 表决定道路负载和高架地铁分担。画面车辆、行人是完整流量的可视化抽样，抽样量不改变统计。
- 水电管线沿道路共享，按连通区域分别结算。电力需求为居民 × 0.6 + 已就业 × 0.8 kW；用水为居民 × 0.12 + 已就业 × 0.04 m³/日。
- 新居民受住房、岗位、电力和水量余量共同限制；小数入住进度会保留。改区不能使已有居民凭空消失。
- 施工按模拟日推进；每层约需 10 日。逐日结算与季度推进共享规则。

## 开发

使用 Node.js 24 和 npm：

    npm install
    npm run dev
    npm run typecheck
    npm test
    npm run build:pages

GitHub Actions 在 main 更新后自动检查、构建、发布，产物为 dist/client。npm run build 保留 Sites / Worker 构建。静态前缀和源站从 Pages 配置读取。

lib/world.ts 保留原野模型与存档；lib/city.ts 提供城市规则；lib/city-renderer.ts 用实例化楼宇、窗灯和交通呈现都市；lib/renderer3d.ts 负责地形、海面、太阳与镜头；lib/terrain3d.ts 是共享的三角地形；lib/use-world.ts 连接交互和存档。

## 验证与边界

自动测试覆盖地形拾取、旧存档、居民/船只导航、城市容量、入住进度、断桥通勤、水电隔离、改区保护、模型导入和新楼宇拾取。另做了纯 CPU 实例矩阵和资源释放检查。没有进行浏览器截图、GPU 编译或视觉验收。

支持可选 WebMCP 城市读取和批量改区接口。当前环境未连接支持的 WebMCP 验证上下文，不宣称浏览器注册执行已验证；不支持该 API 不影响正常游玩。WebGL 2 不可用时采用平面兼容海图。

右侧概念影像为本项目原创生成，明确标为概念影像；主画面由真实模拟状态实时渲染。没有运行时外部图片或字体依赖。
